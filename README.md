Welcome to Axolotl Adventures!!

This game is designed to let you the player play as an axolotl and eat worms that spawn in. You get to start the game choosing what axolotl you would like to be and swim into the underground cave. Level up to unlock new locations, but watch out for the emeries. Collect xp by completing different levels and get faster swimming.
